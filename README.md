# Оно тебе надо

Учебный проект Яндекс Практикума — одностраничный сайт аукциона вещей,
в которые никто не верил.

## Технологии

- семантический HTML5;
- CSS Grid и Flexbox;
- позиционирование и переиспользуемый оверлей;
- локальные шрифты Raleway.

## Запуск

Откройте файл `index.html` в браузере. Сборка и дополнительные зависимости
не требуются.
